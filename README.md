# TradeBot7x

TradeBot7x is a risk-controlled algorithmic trading research and execution platform.

## Current status

Phase 1 foundation is under development.

## Principles

- Paper trading first
- Deterministic strategy and risk engines
- AI assists analysis but cannot override risk controls
- Live trading disabled by default
- Stocks first; options later
- Full audit trail for signals, decisions, and orders

## Planned stack

- Python + FastAPI
- Next.js + TypeScript
- PostgreSQL
- Docker Compose
- Alpaca paper trading API

## Disclaimer

This software is for research and educational use. Trading involves risk, and no strategy or system guarantees profits.
